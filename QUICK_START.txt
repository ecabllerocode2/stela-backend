═══════════════════════════════════════════════════════════════
📋 COMANDOS ESENCIALES (copiar y pegar)
═══════════════════════════════════════════════════════════════

1️⃣  VISTA PREVIA (SIEMPRE PRIMERO)
   
   node migrate-disponible-to-productos.js preview
   
   # Ver más documentos:
   node migrate-disponible-to-productos.js preview 10

───────────────────────────────────────────────────────────────

2️⃣  EJECUTAR MIGRACIÓN COMPLETA
   
   node migrate-disponible-to-productos.js migrate
   
   ⚠️  ADVERTENCIA: Esto guardará en Firestore

───────────────────────────────────────────────────────────────

3️⃣  VERIFICAR RESULTADOS
   
   # Estadísticas generales
   node verify-migration.js stats
   
   # Verificar integridad de datos
   node verify-migration.js verify
   
   # Todo en uno
   node verify-migration.js all

───────────────────────────────────────────────────────────────

4️⃣  ACTUALIZAR COLORES
   
   # Paso 1: Ver productos migrados
   node update-variant-colors.js list
   
   # Paso 2: Generar plantilla para editar
   node update-variant-colors.js template
   
   # Paso 3: Editar colors-template.json con tus colores
   # (ver colors-example.json como referencia)
   
   # Paso 4: Aplicar cambios
   node update-variant-colors.js update colors-template.json
   
   # Extra: Buscar códigos de colores
   node update-variant-colors.js search azul
   node update-variant-colors.js colors

───────────────────────────────────────────────────────────────

5️⃣  GENERAR REPORTE FINAL
   
   node verify-migration.js report

═══════════════════════════════════════════════════════════════
🎯 FLUJO DE TRABAJO RECOMENDADO
═══════════════════════════════════════════════════════════════

FASE 1: PREPARACIÓN

   (Ejecutar la migración completa)

FASE 3: VERIFICACIÓN
├─ node verify-migration.js stats
├─ node verify-migration.js verify

└─ node update-variant-colors.js update colors-template.json

FASE 5: VERIFICACIÓN FINAL
└─ node verify-migration.js all
